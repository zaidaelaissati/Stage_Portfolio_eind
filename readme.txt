# Zaida El Aissati — Portfolio

Welkom op mijn persoonlijke portfolio! 🌟  
Deze website toont mijn WPL-stage bij DeskDrive, inclusief mijn leerproces, werkzaamheden, projecten en wekelijkse blogposts.

🔗 Live demo: https://zaidaelaissati.vercel.app/

---

## 📌 Over dit project

Tijdens mijn laatste jaar Graduaat Programmeren aan AP Hogeschool heb ik deze portfolio-website ontwikkeld om:

- mijn ervaringen tijdens mijn WPL-stage bij DeskDrive te documenteren  
- wekelijkse reflecties en technische inzichten te delen  
- mijn skills en projecten professioneel te presenteren  

De structuur en basis van deze website zijn geïnspireerd op een template van **Colorlib**.  
De layout werd aangepast en uitgebreid met eigen content, blogfunctionaliteit en persoonlijke structuur.

---

## 🧰 Gebruikte technologieën

- HTML5  
- CSS3  
- JavaScript  
- Responsive design  
- Deployment via Vercel  

---

## 📍 Stage Context

Tijdens mijn stage bij DeskDrive werk ik onder andere rond:

- Database backup & restore (Point-in-Time Recovery)  
- PostgreSQL  
- Docker testomgevingen  
- Documentatie & technische analyse  
- CRM & ERP maatwerksoftware  

Deze portfolio toont mijn groei in zowel technische als professionele vaardigheden.
